# OpenClaw

OpenClaw is an open-source multi-agent orchestration framework. You define agents (developer, QA tester, product manager, etc.) via markdown files — similar to `CLAUDE.md` — and those agents interact with each other semi-autonomously, holding "meetings", making decisions, and taking real-world actions. It connects to an LLM backend (such as Claude) and can spin up phone numbers, send messages, or call you when it needs input at 2 AM. Notes coming soon.
